### [Visual Evaluation of Text Embeddings](https://colab.research.google.com/drive/1OadcTOG9HpyHNfLfathBaTP10w72tqfr?usp=sharing)

I compare two Sentence Transformers models by generating text embeddings, applying K-means, and visualizing cluster alignment with existing labels using Sankey and Venn diagrams.
This approach highlights category fragmentation or mixing and can be adapted to customer feedback, incident reports, and product catalogs.

**Key technical components:** Text embedding generation with Sentence Transformers; K-means clustering; Comparison of original labels and cluster assignments; Visual evaluation using Sankey and Venn diagrams.

### [SRPC](https://github.com/oseasandrepro/RPC-LIB)
An experimental Remote Procedure Call(RPC) framework that uses Python as its Interface Definition Language. Define a service contract using Python, implement
the service, generate server and client stubs, and invoke remote procedures. 
The project explore: software architecture design, API design, packaging, versioning, distributed systems, concurrency and maintainability.
